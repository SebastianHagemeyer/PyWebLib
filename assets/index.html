Asset studio

Design a sprite

Build a little sprite out of shapes, publish it, then drop it into any game with game.sprite(id, asset=True). Pick a tool, drag on the canvas to draw, and pick a colour.

Assets need the community backend: a Supabase project with Google sign-in and the assets table from supabase-schema.sql.
